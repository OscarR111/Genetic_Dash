## Cómo ejecutarlo
- 1.Instala GameMaker desde gamemaker.io (hay versión gratuita para uso personal).
- 2.Descarga el proyecto: en la página del repositorio, haz clic en Code → Download ZIP y descomprímelo. Si usas Git: git clone https://github.com/OscarR111/Genetic_Dash.git
- 3.Abre el proyecto: en GameMaker elige Open y selecciona el archivo con extensión .yyp (está en la carpeta principal del proyecto).
- 4.Ejecuta el juego: haz clic en el botón Play (triángulo verde) o presiona F5.
- 5.Controles: tecla de espacio para saltar.
